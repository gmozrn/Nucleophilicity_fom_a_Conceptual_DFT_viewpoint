# Nucleophilicity_fom_a_Conceptual_DFT_viewpoint
Description: Examples of inputs and outputs for the calculated species to obtain the energies I2, I and A for the 203 molecule

Order of archives:
The example correspond to the 203 molecule (5-methoxy-indole)
The procedure followed to obtain the calculated values of I2, I and A follow the next steps:
1. Optimization of the molecule using gaussian09. The example of the input is named opt_203.com and the geometry obtained are extracted in the 203.xyz file
2. Then, the calculation of the dication, cation, neutral and anion of the molecule were performed in Orca with the archive names; dication-203-6311g.in, cation-203-6311g.in, neutro-203-6311g.in, anion-203-6311g.in respectively
3. The energy information obtained from the output files, following the procedure detailed in the article are useful to obtain the I2, I and A energies used to the construction of the indicators developed.
4. The results obtained for the molecules and the experimental data can be found in Tables S1-S5 in the Supporting Information
